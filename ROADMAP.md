# TemplateRepo roadmap

Parent: [Project README](README.md)

This page contains unfinished work only. Implemented behavior belongs in the
README, the documentation or the affected profile.

## Now

- Use the generator for real projects and record repeated friction before
  extending the shared base.

## Later

- Add a profile only after a concrete project needs it more than once.
- Consider optional license selection if fixed MPL-2.0 licensing becomes a real
  blocker.
- Consider a GitHub template publication workflow after the local generator has
  proven stable.
